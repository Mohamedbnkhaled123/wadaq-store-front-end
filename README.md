# متجر ودق للأدوات الحسية وتجهيز الغرف (Wadaq Sensory Store)

مشروع متجر وموقع متكامل لمتجر **ودق للتنمية والتدريب** المتخصص في أدوات التكامل الحسي، التخاطب، وتجهيز غرف ومراكز السنوزلين والعلاج الوظيفي، مبني باستخدام **MEAN Stack** بالكامل مع دعم العرض على الخادم (SSR) وتحسين محركات البحث (SEO).

---

## 🏗️ التقنيات المستخدمة (Tech Stack)

### الباك إند (Backend - Express & Node.js & TypeScript)
- **Node.js 24 + Express 5** مع TypeScript صارم.
- **MongoDB + Mongoose 9** لتخزين البيانات والـ Schemas.
- **JWT + HTTP-Only Cookies** لمصادقة لوحة التحكم بأمان كامل ضد XSS.
- **Express-Rate-Limit** لحماية شاشة تسجيل الدخول من محاولات التخمين (12 محاولة / 15 دقيقة).
- **Multer + Cloudinary** لرفع وإدارة صور المنتجات والمشاريع.
- **In-Memory Cache (TTL)** لتسريع استجابة التصنيفات والصفحة الرئيسية مع إبطال تلقائي عند التعديل (Cache Invalidation).

### الفرونت إند (Frontend - Angular 21 SSR)
- **Angular 21** بتقنية Standalone Components و Signals و Zoneless Hydration.
- **Angular SSR (Server-Side Rendering)** لسرعة تحميل فائقة وفهرسة مثالية في Google و Bing.
- **Transloco** لدعم اللغتين العربية والإنجليزية ديناميكياً مع دعم اتجاه الصفحة (RTL/LTR).
- **Schema.org JSON-LD** لكل منتج وباقة لظهور الأسعار والتوافر في نتائج البحث المتقدمة (Rich Snippets).
- **سلة تسوق محلية (Local Storage Cart)** مع درج سلة جانبي متحرك (Drawer).

## 🌟 الميزات والمطالب الخاصة المنفذة بدقة

1. **نظام الشراء عبر الواتساب (WhatsApp Purchase Flow):**
   - **منتج مفرد:** زر "اشتري الآن عبر واتساب" يقوم بإنشاء رسالة منسقة تتضمن: رابط المنتج، اسم المنتج بالعربية/الإنجليزية، رابط الصورة، السعر، الكمية، وملاحظة `+ مصاريف الشحن حسب المحافظة وموقع التوصيل`.
   - **سلة مشتريات (أكثر من منتج):** زر تأكيد السلة يرسل قائمة كاملة بأسماء المنتجات، كمياتها، أسعارها، الإجمالي، رابط المتجر، رابط الشعار، وملاحظة `+ مصاريف الشحن`.
   - **باقات تجهيز الغرف:** زر مخصص لطلب عرض سعر ودراسة هندسية للغرفة الحسية عبر الواتساب.
   - **طلب أداة مخصصة (Custom Tool Inquiry):** بانر مخصص في أسفل صفحة المنتجات والصفحة الرئيسية يتيح للأخصائي طلب تصنيع أو توفير أداة بمقاسات أو مواصفات خاصة عبر الواتساب.

2. **التعامل مع المنتجات المحذوفة والمعطلة (Soft-Delete & Deactivation):**
   - في حال تم إيقاف تنشيط المنتج (`isActive: false`) أو حذفه مؤقتاً (`isDeleted: true`)، يظل رابط المنتج يعمل (200 OK) لحفظ قوة السيو وتجربة المستخدم.
   - تظهر للمستخدم كامل مواصفات المنتج وبياناته مع بانر تنبيهي واضح: **"هذا المنتج غير متاح حالياً"**.
   - يتم تعطيل أزرار الشراء والإضافة للسلة تلقائياً.

3. **حماية سلة الشراء من حساب الأدمن:**
   - الأدمن عند تسجيل دخوله للوحة التحكم لا يستطيع الشراء أو إضافة منتجات للسلة، وتظهر له رسالة توضيحية مع زر سريع للانتقال لتعديل المنتج في الداشبورد.

4. **لوحة التحكم الشاملة (Admin Dashboard):**
   - رابط تسجيل الدخول: `http://localhost:4200/admin/login`
   - **البريد الافتراضي:** `admin@wadaq.com`
   - **كلمة المرور الافتراضية:** `AdminWadaq@2026`
   - إدارة كاملة للمنتجات (إضافة، تعديل، حذف مؤقت، استعادة، تعطيل/تنشيط، تصنيف، مواصفات).
   - إدارة تصنيفات الأدوات الحسية.
   - إدارة باقات تجهيز الغرف الحسية وتعديل أسعارها ومحتوياتها.
   - إدارة معرض مشاريع التجهيز السابقة (صور، وصف، المركز).
   - نظام إدارة المحتوى (CMS) لتعديل رقم واتساب المبيعات، ملاحظة الشحن، ونصوص الموقع.

5. **خريطة الموقع التلقائية (Dynamic Sitemap):**
   - مسار السايت ماب: `http://localhost:4200/sitemap.xml`
   - يشمل كافة روابط المنتجات والتصنيفات والباقات والمشاريع باللغتين مع وسوم `xhtml:link` البديلة.

## 🚀 كيفية تشغيل المشروع محلياً (Quick Start)

### 1. تشغيل الباك إند (Backend)
```powershell
cd "d:\Programing\MEAN stack\Wadaq store back end"
npm run dev
```
- سيعمل الخادم على: `http://localhost:4000`
- فحص الحالة: `http://localhost:4000/api/health`

### 2. تشغيل الفرونت إند (Frontend)
```powershell
cd "d:\Programing\MEAN stack\Wadaq store front end"
npm start
```
- سيعمل المتجر على: `http://localhost:4200`
- لوحة التحكم: `http://localhost:4200/admin/login`

### 3. زرع البيانات الأولية (Seeding)
قاعدة البيانات تحتوي بالفعل على بيانات أولية نموذجية كاملة (أدوات، باقات، مشاريع، تصنيفات، وحساب الأدمن). لإعادة الزرع في أي وقت:
```powershell
cd "d:\Programing\MEAN stack\Wadaq store back end"
npm run seed
```
